# Executive Summary Dashboard

## Project Overview
This project presents a sales and operational performance dashboard designed to summarize key business metrics and make performance comparisons easier.

## Dashboard Features
- **Profit by Region:** Compare profit across five regions.
- **Profit by Customer Segment:** Compare profitability across customer segments.
- **Daily Sales Trend:** Review sales patterns across the days of the week.
- **Sales by Year:** Visualize sales distribution by year.
- **Average Day to Pack:** Review average packing time by product category.
- **Total Sales by Day Type:** Compare weekday and weekend sales.
- **Interactive Filters:** Explore results by Order Priority and Ship Mode.
